    Pair / connect

    ⚠ The mower must be sitting in its charging station before pairing.

    How to prepare the mower for pairing:
    1. Place the mower in the charging station and confirm the charging LED is lit.
    2. Close the Flymo / Husqvarna app on your phone — only one BLE connection is allowed at a time.
    3. If the mower was previously paired to a phone, you may need to remove it from the phone's Bluetooth settings first.
    4. Enter the operator PIN below (default 1234). If the mower was set up with the app, the PIN may have been changed — check the original installation paperwork or the app settings.
    5. Click Save & connect. The bridge will connect automatically within a few seconds.

    EasiLife GO 400 button reference (for PIN entry on the mower keypad if required):
    1 = Power  |  2 = Play/Schedule  |  3 = Go (arrow)  |  4 = Home/Park

    WiFi

      Admin credentials

      Password authentication for the web UI. Off by default. If you enable it and get locked out, hold the BOOT button >5 s to wipe settings.

      MQTT broker

      Web Flashing Mode

      Enable this before uploading firmware from the browser. Bluetooth will be disabled after reboot so the device can accept the OTA flash safely. Re-enable it when you are finished.

      Firmware OTA

      Select the firmware binary and upload. The web UI is bundled into the firmware — a single firmware.bin is the only file needed.

      If you are flashing from the browser, enable Web Flashing Mode first, then upload the firmware binary and allow the device to reboot.
